Business Continuity Schema Help

Overview

The business continuity schema file contains a collection of activities, each with its own set of data. The file is organized into an array of objects, with each object representing a single activity.

Activity Structure

  • keyName: A unique identifier for the activity
  • label: A human-readable label for the activity
  • title: A title or name for the activity
  • type: The type of data that is being stored for this activity (e.g. text, number, etc.)
  • value: The value of the data being stored for this activity
  • showChart: A boolean indicating whether the data should be displayed as a chart
  • statusActivities: An array of status updates for this activity (e.g. pending, processing, complete)
  • subActivities: An array of sub-activities that are part of this activity

Activity Types

  • text: Plain text data
  • html: HTML-formatted text data
  • boolean: A boolean value (true or false)
  • int: An integer value
  • float: A floating-point value
  • percentage: A percentage value
  • slider: A slider value
  • timeline: A timeline value
  • duration: A duration value (e.g. number of days)
  • severity: A severity level (e.g. high, low)
  • trend: A trend direction (e.g. up, down)
  • dr: A "dr" value (not clear what this represents without more context)

Sub-Activities

Sub-activities are activities that are part of a larger activity. They are represented by objects that contain similar properties to the main activity.

Example

The following is an example of an activity in the model data file:

  {
    "keyName": "A",
    "label": "A",
    "title": "A1",
    "type": "text",
    "value": "this is text area",
    "showChart": false,
    "statusActivities": [
      {
        "status": "Pending/Processing/Complete etc...",
        "color": "#3b82f6",
        "dateTime": "2026-11-06T11:11"
      }
    ],
    "subActivities": [
      {
        "keyName": "A1",
        "label": "A1",
        "title": "Pending/Processing/Complete etc...",
        "type": "text",
        "value": "Sub Text area",
        "showChart": false,
        "statusActivities": [
          {
            "status": "Pending/Processing/Complete etc...",
            "color": "#3b82f6",
            "dateTime": "2026-11-06T11:11"
          }
        ],
        "subActivities": []
      }
    ]
  }

This example shows an activity with a key name of "A", a label of "A", and a title of "A1". It also has a type of "text", a value of "this is text area", and a boolean indicating whether to show a chart.

Accessing the Business Continuity Schema File

The business continuity schema file can be accessed by opening the file in a text editor or IDE, or by using a programming language to read the file and parse its contents.
